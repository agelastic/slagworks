# SLAGWORKS

A small retro first-person shooter that runs in the browser. You are a salvage mechanic working
your way out of a derelict orbital foundry whose maintenance machines have turned on anyone who
walks the floor. There are four levels, five weapons, five kinds of machine and a boss at the core.

It is built for iPhone Safari first and also plays on desktop browsers. Everything (textures,
sprites, sound effects and music) is generated by code when the page loads. There are no asset
files, no dependencies at runtime and no build step.

## How to play

Touch:

- Left thumb: drag to move. The stick appears where your thumb lands.
- Right thumb: drag to turn.
- FIRE: hold to shoot. Keep dragging the same finger to aim while firing.
- USE: doors, switches and the exit. Walking into them works too.
- WPN: next weapon.
- Minimap (top right): tap for the full map.
- Pause button: top left.

Keyboard and mouse:

- W A S D or the arrow keys: move (left and right arrows turn).
- Mouse: turn. Click the view to capture the pointer.
- Left button or F: fire.
- E or Space: use.
- 1 to 5, Q or the mouse wheel: weapons.
- M or Tab: map.
- Esc or P: pause.

A gamepad with the standard mapping also works.

On an iPhone, tap Share and then Add to Home Screen, and start the game from the new icon. It then
runs full screen without the Safari toolbars.

The game saves at the start of each level. Continue on the title screen picks up from there.

## Running it locally

```
node tools/serve.mjs
```

Then open http://localhost:8080. The server listens on all interfaces, so a phone on the same
network can open `http://<your computer's address>:8080`. Any static file server works; the game
uses relative URLs only, so it can also be served from a subpath such as GitHub Pages.

## Tests

```
npm install                       # playwright-core, used only by the browser test
node tools/validate-levels.mjs    # level structure, reachability, ammo and health budgets
node tools/sim-test.mjs           # game logic in Node: fixtures, fuzzing, a bot that finishes every level
node tools/browser-test.mjs       # headless Chrome: menus, touch controls, every level, screenshots
node tools/dump-assets.mjs textures   # texture sheet as PNG
node tools/dump-assets.mjs sprites    # sprite atlas as PNG
```

`npm test` runs the first three. The browser test uses the installed Google Chrome and writes its
screenshots to `out/browser-test/`.

For testing in the browser, `?autostart=1&level=3&difficulty=2` starts straight into a level
(1 to 4) with every weapon, and `?god=1` makes the player take no damage.

## Layout

```
index.html, style.css   page and styles
src/main.js             boot, state machine, frame loop
src/config.js           names and constants shared by all modules
src/core/               seeded RNG and a small pixel-drawing library
src/assets/             procedural textures and sprites
src/audio.js            synthesised sound effects and music
src/input.js            touch, keyboard, mouse and gamepad
src/game/               game logic (pure JS, runs in Node)
src/levels/             the four levels
src/render/             WebGL renderer
src/ui/                 HUD, minimap and menus
tools/                  dev server and tests
```
